# Code of conduct

## The short version

Be decent. Assume the person on the other side is competent and acting in good
faith, and write as if you will have to work with them next week.

## Expected behaviour

- Keep criticism aimed at code, decisions and evidence — never at people.
- Accept that others may weigh trade-offs differently than you do. Say why you
  disagree, then let the maintainer decide.
- Respect that this project is maintained in spare time. An unanswered issue is
  not an insult.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, sustained disruption, and
publishing others' private information without permission.

## Scope

This applies in the issue tracker, pull requests, commit messages, and any
other project space.

## Enforcement

Report problems privately to the maintainer — see
[SECURITY.md](SECURITY.md) for the private reporting channels.
Reports are handled privately. Consequences range from a request to change
behaviour up to a block from the project, depending on severity.

The maintainer decides. There is no committee.
